# 时间线 Timeline

一个面向「事项 / 任务 / 事件」的网页版时间轴管理工具。竖向时间轴 + 横向甘特图，事项与任务一目了然，支持长按拖拽平移、单文件离线运行，数据自动保存在本地浏览器。

## 功能特性

- **竖向时间轴**：以「天」为行，左侧时间轴显示日期；月份标签定位在每个月的 1 日处，一月额外显示年份；顶部固定块始终显示当前可见的「年份 + 月份」。
- **事项（Event）**：在时间轴对应日期上以圆点 + 标签标记。同一天事项过多时自动折叠为 `+N` 徽标，点击弹出当日全部事项列表。
- **任务（Task）**：横向条块（甘特图），自动分列避免重叠；时间跨度大的任务，其名称 / 时间 / 进度描述会始终贴在可见区域上沿，**只要屏幕上能看到条块，就能看到它的描述**。
- **平移与翻页**：支持鼠标滚轮、按住拖拽（横向 / 竖向）平移视图；滚动到顶 / 底会自动向过去 / 未来扩展一个月。
- **本地持久化**：事项与任务保存在浏览器 `localStorage`，刷新和重开都不丢失（首次打开为示例数据）。
- **单文件离线运行**：构建产物为内联全部资源的单文件 HTML，双击即可在浏览器打开，无需服务器、无需安装环境。

## 运行方式

### 方式 A：直接打开（最简单，推荐普通用户）

双击仓库根目录的 **`时间线.html`** 即可在浏览器中使用。该文件已内联所有 JS / CSS，可拷贝、可分享，免安装。

### 方式 B：开发者模式

```bash
npm install      # 安装依赖
npm run dev      # 开发预览，默认 http://localhost:5173
npm run build    # 生产构建，产出内联单文件 dist/index.html（即 时间线.html 的源）
npm run preview  # 预览构建产物，默认 http://localhost:4173
```

> 构建后若要把 `dist/index.html` 当作独立交付物，重命名为 `时间线.html` 即可双击打开。

## 数据说明

- 当前无后端。所有数据存于浏览器 `localStorage`（键名 `timeline-events` / `timeline-tasks`）。
- 换浏览器、清缓存或隐私模式会拿不到数据；如需多端同步需自行接入后端。
- 想重置为示例数据：清空对应 localStorage 键，或删除后重新打开。

## 已知限制

- **移动端**：已加 `<meta viewport>`，手指滑动可滚动，但「按住拖拽平移」依赖鼠标事件，手机上不可用；布局为桌面尺寸，未做响应式适配。
- **无协作 / 无云同步**：数据仅在本机浏览器。
- **示例数据**位于 `src/data/mockData.ts`，接真实数据时替换此处即可。
